### 2. Fix Confidence Bug (HIGH)

**Current**: `confidence = (soh_healthy_prob + (1 - rul_short_prob)) / 2`  
**Issue**: Returns ~0 when SOH is class 0 (Not-Healthy)

**Fix**:
```python
def calculate_confidence(soh_proba, rul_proba):
    soh_conf = max(soh_proba)  # Confidence in predicted class
    rul_conf = max(rul_proba)
    return (soh_conf + rul_conf) / 2
```

Would correctly report 99.99% confidence for current predictions
