🚀 What is Battery Health Prediction System?

Battery Health Prediction System is a professional desktop application that uses advanced AI and machine learning to analyze the health and remaining life of Li-ion batteries. Built on NASA battery degradation research data, our models provide accurate predictions to help you understand your battery's condition.

How AI Powers the App: The system uses two trained ML models - a Logistic Regression classifier for State of Health (SOH) prediction and a Random Forest classifier for Remaining Useful Life (RUL) estimation. Both models were trained on 2,247 real NASA battery cycling samples with 27 engineered features per prediction, ensuring high accuracy and reliability.

Who Is This For? Perfect for battery researchers, electronics engineers, EV enthusiasts, data scientists, students, and anyone working with Li-ion batteries who needs to assess battery health and predict remaining useful life.

📋 Installation Instructions

🪟 Windows (10/11 - 64-bit)

  1. Download the Battery Health Prediction Setup 1.0.0.exe file
  2. Locate the downloaded file (usually in your Downloads folder)
  3. Right-click and select "Run as Administrator" (recommended) or double-click to run
  4. If Windows SmartScreen appears, click "More info" then "Run anyway" (the app is safe - this appears for new applications)
  5. Follow the installation wizard - accept the license and choose installation location
  6. Wait for installation to complete (~1-2 minutes)
  7. Launch the app from Start Menu or Desktop shortcut
  8. Test files are automatically copied to your Desktop for quick testing

Note: The installer includes Python runtime, ML models, and all dependencies - no additional setup required!

🍎 macOS (10.15+ Catalina or later)

  1. Download the Battery Health Prediction 1.0.0.dmg file
  2. Open the downloaded DMG file
  3. Drag the Battery Health Prediction app icon to the Applications folder
  4. Eject the DMG from Finder
  5. Open Applications folder and find Battery Health Prediction
  6. Right-click the app and select "Open" (first time only)
  7. If macOS asks, click "Open" to confirm (the app is safe and notarized)
  8. The app will launch - you're ready to analyze batteries!

Note: If you see "App can't be opened", go to System Preferences → Security & Privacy → Click "Open Anyway"

🐧 Linux (Ubuntu 20.04+, Debian, Fedora)

Option A: AppImage (Universal)
  1. Download the Battery-Health-Prediction-1.0.0.AppImage file
  2. Open terminal and navigate to download location: cd ~/Downloads
  3. Make executable: chmod +x Battery-Health-Prediction-1.0.0.AppImage
  4. Run: ./Battery-Health-Prediction-1.0.0.AppImage
  5. (Optional) Move to Applications: sudo mv Battery-Health-Prediction-1.0.0.AppImage /opt/
Option B: .deb Package (Ubuntu/Debian)
  1. Download the battery-health-prediction_1.0.0_amd64.deb file
  2. Install: sudo dpkg -i battery-health-prediction_1.0.0_amd64.deb
  3. Fix dependencies (if needed): sudo apt-get install -f
  4. Launch: Search for "Battery Health Prediction" in applications or run battery-health-prediction

Note: Requires X11/Wayland display server. Tested on Ubuntu 22.04, Debian 11, Fedora 38.
