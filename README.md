# Battery Health Prediction System

NASA Li-ion Battery Degradation Analysis

## Installation

```bash
npm install
```

## Running the Application

```bash
npm start
```

## Purpose

Desktop application for analyzing NASA lithium-ion battery datasets and predicting State of Health (SoH) and Remaining Useful Life (RUL) using machine learning models.

## Features

- CSV file upload with drag-and-drop support
- Real-time battery health analysis
- State of Health (SoH) prediction
- Remaining Useful Life (RUL) estimation
- Degradation trend visualization
- Professional scientific interface for research and aerospace environments
